# 1_DoF_duocopter_control_system# 1-DoF Duo-Copter Physics Model

## Overview

This project implements a **single-input single-output (SISO) physics model** of a 1-DoF duo-copter system in MATLAB Simulink. The model simulates the vertical dynamics of a constrained duo-copter platform under throttle input, producing system height response as output.

The simulation was developed for the Imperial College London Design-Build-Test (DBT) exercise and is based on first-principles physics modelling using Newtonian mechanics.

The physical system includes:

* Variable mass dynamics
* Nonlinear thrust modelling
* Continuous friction modelling
* Boundary collision handling
* Discrete-time numerical integration

---

# System Architecture

The physics model is divided into three primary subsystems:

1. **Mass Subsystem**
2. **Thrust Subsystem**
3. **Friction Subsystem**

The overall equation of motion is:

[
M_{\text{effect}} \ddot{h} = T - Mg - f
]

Where:

| Variable            | Description           |
| ------------------- | --------------------- |
| (M_{\text{effect}}) | Effective system mass |
| (\ddot{h})          | Vertical acceleration |
| (T)                 | Motor thrust          |
| (Mg)                | Gravitational force   |
| (f)                 | Friction force        |

---

# Effective Mass Model

The system mass is not constant due to cable loading effects. The effective mass is modelled as:

[
M_{\text{effect}} =
2(m_{\text{motor}} + m_{\text{propeller}} + m_{\text{ESC}} + m_{\text{arm}} + m_{\text{cable loaded}})

* m_{\text{carriage}}

- m_{\text{counterweight}}
  ]

## Cable Mass Approximation

Although the cable physically forms a catenary curve, the simulation approximates it using a simplified linearly height-dependent U-shaped model to reduce computational complexity.

[
m_{\text{cable loaded}}
=======================

m_{\text{cable total}}
\cdot
\frac{\Delta y + L_{\text{total}}}{2L_{\text{total}}}
]

Where:

| Variable                 | Description              |
| ------------------------ | ------------------------ |
| (m_{\text{cable total}}) | Total cable mass (190 g) |
| (\Delta y)               | Vertical displacement    |
| (L_{\text{total}})       | Total cable length (1 m) |

---

# Friction Model

The model uses a **continuous Stribeck friction model** with viscous damping to eliminate discontinuities associated with classical piecewise friction switching.

The implemented friction equation is:

[
f =
---

\left(
F_d + (F_s - F_d)e^{-(|v|/v_s)^2}
\right)
\tanh\left(\frac{v}{v_t}\right)
-------------------------------

cv
]

Where:

| Parameter | Description                    |
| --------- | ------------------------------ |
| (F_s)     | Static friction force (1.28 N) |
| (F_d)     | Dynamic friction force         |
| (v)       | Velocity                       |
| (v_s)     | Stribeck velocity              |
| (v_t)     | Smoothing velocity             |
| (c)       | Viscous damping coefficient    |

## Dynamic Friction

Dynamic friction is computed using:

[
F_d = \mu_k F_N
]

with:

[
\mu_k = 0.155
]

This value was conservatively selected within experimentally observed bounds.

# Thrust Characterisation

The thrust generated by the 28-35 motors was experimentally characterised and fitted using:

* A **7th-order polynomial regression**
* An **asymptotic exponential saturation model**

## Polynomial Region

For:

[
u \leq 79.04
]

[
T(u)=
Au^7 + Bu^6 - Cu^5 + Du^4 + Eu^3 + Fu^2 + Gu + H
]

## Saturation Region

For:

[
u > 79.04
]

[
T(u)=7.68 -0.11e^{-0.47(u-79.04)}
]

Where:

| Variable | Description        |
| -------- | ------------------ |
| (T)      | Thrust             |
| (u)      | Throttle input (%) |

The asymptotic model provides smoother behaviour near motor saturation compared to a constant saturation model.

# Numerical Integration

The model uses:

* Discrete-time integration
* Fixed timestep:

[
\Delta t = 0.05s
]

* ODE45 solver for improved numerical stability

Unit delay blocks were included within the feedback loop to ensure proper discrete implementation.

---

# Boundary Collision Modelling

The physical rail boundaries were modelled using:

* Zero acceleration constraints at upper and lower limits
* Integral reset logic
* Velocity clamping

To simulate highly damped inelastic impacts, a **Rate Limiter** with slew rate:

[
\pm 200 \text{ m/s}^2
]

was implemented to smooth velocity transitions during collisions.
